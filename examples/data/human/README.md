The file 'connectivity.npy' corresponds to a 3D array that contains the structural connectivity
matrices of 70 individual subjects [1]. 

The file 'consensus_0.npy' corresponds to a 2D array that contains the group-level structural
connectivity matrix of the 70 individual subjects in [1].  

The files 'consensus_X.npy' (where X = [1, 5]) correspond each to a 2D array that contain a 
group-level structural connectivity matrix obtained from a bootstrapped sample of the 70 individual 
subjects in [1].
